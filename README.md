# What Flow Deleted

A portfolio by pavittt, built by voice with Wispr Flow for the Wispr Flow India growth challenge.

Wispr Flow deletes the "um"s. This site is about what was in them: six projects, six real voice notes, and the mistakes I made building each one. Scroll through each project to see what I built, what went wrong and what I kept. Press play to hear the unedited voice note. Turn Flow on to see what Wispr Flow actually wrote when I told the same story.

Plain HTML, GSAP + ScrollTrigger, Lenis and three.js. No build step.

Live site: https://pavittt.github.io/what-flow-deleted/
